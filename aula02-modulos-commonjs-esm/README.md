📚 Sobre o projeto
O projeto demonstra como:

Utilizar ES Modules (ESM) no Node.js.
Importar módulos nativos do Node.js.
Criar e utilizar módulos próprios.
Utilizar import e export.
Trabalhar com arquivos de forma assíncrona usando fs/promises.
Criar diretórios automaticamente.
Registrar mensagens em um arquivo de log.
Formatar data e hora para os registros.
🛠️ Tecnologias utilizadas
Node.js
JavaScript
ES Modules (ESM)
fs/promises
path
url
📋 Funcionamento
Quando o projeto é executado, o programa:

Inicializa a aplicação.
Cria a pasta logs, caso ela ainda não exista.
Cria o arquivo system.log, caso ele ainda não exista.
Formata a mensagem com data e hora.
Adiciona a mensagem ao arquivo utilizando appendFile.
Registra duas mensagens no arquivo.
Exibe no terminal uma confirmação de que o log foi registrado.
