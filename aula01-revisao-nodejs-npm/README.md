# 🖥️ Diagnóstico do Servidor

Script desenvolvido em **Node.js** para obter informações básicas sobre o sistema operacional e o hardware da máquina.

## 📋 Sobre o projeto

Este projeto utiliza o módulo nativo `os` do Node.js para coletar informações do sistema, como:

- 🖥️ Arquitetura/plataforma do sistema operacional
- 💾 Memória RAM total
- 📊 Memória RAM disponível
- ⚙️ Quantidade de CPUs
- 🔧 Modelo do processador

As informações são exibidas diretamente no terminal.

## 🚀 Tecnologias utilizadas

- [Node.js](https://nodejs.org/)
- Módulo nativo `os` do Node.js
- JavaScript
