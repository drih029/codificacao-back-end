Projeto desenvolvido durante a aula sobre **Middlewares e Interceptors** utilizando NestJS.

## Tecnologias

- NestJS
- TypeScript
- Node.js
- Vitest

Nesta aula foram abordados:

- Middlewares
- Criação de middleware personalizado
- Interceptors

- Logging de requisições
