# 🚀 codificação back-end
Repositório dedicado aos meus estudos e projetos de desenvolvimento back-end, com foco em programação, APIs, bancos de dados, lógica de negócio e boas práticas de desenvolvimento.

# 📌 Sobre
Este repositório reúne exercícios, projetos e experimentos realizados ao longo da minha jornada de aprendizado em desenvolvimento back-end.

O objetivo é colocar em prática conceitos fundamentais e evoluir continuamente minhas habilidades como desenvolvedor.
